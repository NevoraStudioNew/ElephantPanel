# ElephantPanel

Panel server ala Pterodactyl, jalan langsung di HP Android — tanpa root, tanpa VPS.

Repo ini adalah **tempat rilis resmi** ElephantPanel: unduhan APK, catatan rilis, dan dokumentasi fitur. Kode sumber bersifat proprietary dan tidak dipublikasikan di sini. Lihat [LICENSE](LICENSE) untuk ketentuan pemakaian.

Dibuat oleh **Nevora Studio**.

## Unduh

Unduh APK terbaru di tab [Releases](../../releases) repo ini. Setiap rilis menyertakan catatan perubahan (changelog) di deskripsinya.

## Fitur singkat

- Kelola banyak server dalam satu app: console, file manager, startup, backup, schedule
- Shell terminal asli (PTY) berbasis emulator Termux + runtime Alpine Linux
- Egg/template server siap pakai ala Pterodactyl
- Grafik pemakaian CPU/RAM/disk per server
- PIN panel dan service latar belakang biar server tetap jalan
- Cek update otomatis + pop up catatan rilis
- Server yang sedang berjalan otomatis pulih lagi setelah HP reboot atau app diupdate

Penjelasan lengkap tiap fitur ada di folder [docs](docs).
